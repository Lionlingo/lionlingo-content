en:
  # Purpose

  to / in order to / so that explain why you do something.

  - to / in order to + verb · so that + clause
  - I left early to catch the bus.
fr:
  # Propositions de but

  Expliquez pourquoi une action est faite.

  - pour / afin de + infinitif ; pour que + subjonctif.
  - Je suis parti tôt pour prendre le bus. · Parle plus fort pour qu’on entende.
de:
  # Finalsätze / Absicht

  Erklären Sie, warum eine Handlung geschieht.

  - um … zu + Infinitiv; damit + Nebensatz.
  - Ich ging früh, um den Bus zu erwischen. · Sprich lauter, damit wir hören.

  አንድ ተግባር ለምን እንደተደረገ ያብራሩ።

ar:
  # جمل الغرض

  اشرح لماذا يُفعل الفعل.

  - لـ / من أجل + مصدر؛ لكي / حتى + مضارع.
  - غادرت مبكراً لألحق بالحافلة. · تكلّم أعلى لكي نسمع.
es:
  # Oraciones de finalidad

  Explica por qué se hace una acción.

  - para / a fin de + infinitivo; para que + subjuntivo.
  - Salí temprano para coger el bus. · Habla más alto para que oigamos.
ja:
  # 目的の表現「ために／ように」

  行動の目的を説明します。

  - 〜ために＋動詞。／〜ように＋文。
  - バスに乗るために早く出た。・聞こえるように大きく話して。
zh:
  # 目的小句：为了／以便

  说明做某事的目的。

  - 为了＋动词；以便／好让＋小句。
  - 我早点出门是为了赶上公交。・大声点，好让我们听见。
