en:
  # Emphatic do

  do/does/did before the verb adds stress or contradiction.

  - do/does/did + verb (stress)
  - I do understand. · We did try.
fr:
  # Emphase : bien / si / accent

  Renforcez l’affirmation ou le contraste.

  - Utile pour corriger ou insister.
  - Je comprends bien. · Si, j’aime ça !
de:
  # Betonung

  Verstärken Sie eine Aussage oder einen Kontrast.

  - Häufig beim Korrigieren oder Beharren.
  - Ich verstehe das wirklich. · Sie kümmert sich doch.
am:
  # ማጉላት

  ግሥን ለማረጋገጥ ወይም ለመቃረን ያጉሉ።

  - በርግጥ እረዳለሁ። · እሷ ትጨነቃለች።
  - ሲያርሙ ወይም ሲያጥብቁ የተለመደ።
ar:
  # التوكيد: فعلاً / إنّ / لقد

  شدّد لإثبات الفعل أو إبرازه.

  - لست أكرهه — أنا أحبه فعلاً.
  - أنا أفهم فعلاً. · إنها تهتم حقاً.
es:
  # Énfasis: sí / de verdad / sí que

  Añade fuerza para afirmar o contrastar.

  - No es que no me guste — sí me gusta.
  - Sí que entiendo. · Ella sí se preocupa.
ja:
  # 強調「確かに／どうしても／〜はする」

  動詞を肯定・対比で強めます。

  - 嫌いなのではなく、好きではあります。
  - 確かに分かります。・彼女は気にしています。
zh:
  # 强调：确实／的确／是……的

  加强肯定或对比。

  - 我不是不喜欢——我确实喜欢。
  - 我确实明白。・她的确在乎。
