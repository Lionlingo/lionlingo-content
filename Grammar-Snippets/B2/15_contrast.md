en:
  # Contrast

  although, however, whereas, despite show contrast.

  - although · however · whereas · despite
  - Although it rained, we went out.
fr:
  # Connecteurs de contraste

  Signalez clairement l’opposition entre idées.

  - bien que / même si + subjonctif/indicatif ; cependant / néanmoins.
  - Bien qu’il pleuve, nous sommes sortis. · Cependant, le plan a échoué.
de:
  # Kontrastkonnektoren

  Markieren Sie den Gegensatz zwischen Ideen klar.

  - obwohl + Nebensatz; jedoch / dennoch + Hauptsatz.
  - Obwohl es regnete, gingen wir raus. · Allerdings scheiterte der Plan.
am:
  # የንጽጽር ማያያዣዎች

  በሀሳቦች መካከል ያለውን ተቃርኖ በግልጽ ያሳዩ።

  - ምንም እንኳን… ቢሆንም፤ ሆኖም / ነገር ግን።
  - በተቃራኒ / ሲሆን ሁለት እውነታዎችን ያነጻጽራል።
ar:
  # روابط التعارض

  أظهر التعارض بين الأفكار بوضوح.

  - مع أنّ / رغم أنّ + جملة؛ ومع ذلك / غير أنّ.
  - مع أنه هطل المطر، خرجنا. · ومع ذلك فشل الخطة.
es:
  # Conectores de contraste

  Señala con claridad la oposición entre ideas.

  - aunque + indicativo/subjuntivo; sin embargo / no obstante.
  - Aunque llovía, salimos. · Sin embargo, el plan falló.
ja:
  # 対比の接続表現

  考えの対立をはっきり示します。

  - 〜けれども／〜のに。しかし／それでも。
  - 雨が降ったけれども出かけた。・しかし計画は失敗した。
zh:
  # 转折连接词

  清楚标示意思之间的对立。

  - 虽然／尽管＋小句；然而／不过＋句子。
  - 虽然下雨，我们还是出门了。・然而计划失败了。
