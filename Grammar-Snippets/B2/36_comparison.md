en:
  # Comparison

  English adds -er and -est or uses more and most.

  - Short adjectives: big → bigger → the biggest
  - Long adjectives: more interesting → the most interesting
  - Irregular: good → better → the best
fr:
  # Le comparatif et le superlatif

  Le français utilise plus, moins et aussi.

  - plus … que · moins … que · aussi … que : Il est plus grand que moi.
  - le plus · le moins : le plus grand
  - Irrégulier : bon → meilleur → le meilleur
de:
  # Komparativ und Superlativ

  Das Adjektiv bekommt -er und am -sten.

  - Komparativ + als: größer als · schneller als · alt → älter
  - Superlativ: am größten · am schnellsten · so … wie für gleich
  - Unregelmäßig: gut → besser → am besten · gern → lieber → am liebsten

ar:
  # المقارنة والتفضيل

  تستعمل العربية صيغة أفعل للمقارنة.

  - كبير → أكبر · طويل → أطول: هو أطولُ مني.
  - التفضيل: الأطولُ
  - المساواة: هو طويلٌ مثلي.
es:
  # Comparativo y superlativo

  El español usa más, menos y tan.

  - más … que · menos … que · tan … como: Es más alto que yo.
  - el más · el menos: el más alto
  - Irregulares: bueno → mejor · malo → peor · grande → mayor
ja:
  # 比較

  日本語は「より」と「いちばん」を使います。

  - ＿より…：私より背が高いです。
  - いちばん：いちばん高いです。
  - 同じくらい：私と同じくらい高いです。
zh:
  # 比较

  汉语用「比」和「最」。

  - 他比我高。
  - 他最高。
  - 他跟我一样高。
