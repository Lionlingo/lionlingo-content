en:
  # To become

  English uses become and get for change.

  - become + noun: She became a doctor.
  - get + adjective: It gets dark. · I got tired.
  - Future uses will, and the passive uses be: I will go. · The door is opened.
fr:
  # Devenir

  Devenir exprime un changement.

  - devenir + nom : Elle est devenue médecin.
  - devenir + adjectif : Il devient grand.
  - Futur avec aller, passif avec être : Je vais partir. · La porte est ouverte.
de:
  # Werden

  Werden hat drei Aufgaben.

  - werden = Veränderung: Sie wird Ärztin. · Es wird dunkel.
  - Futur: werden + Infinitiv: Ich werde gehen.
  - Passiv: werden + Partizip II: Die Tür wird geöffnet.

ar:
  # صار وأصبح

  تعبّر العربية عن التحوّل بصار وأصبح.

  - صار / أصبح + اسم منصوب: صارت طبيبةً.
  - + صفة: أصبح الجوّ بارداً.
  - المستقبل بـ سـ والمبني للمجهول بتغيير الحركة: سأذهب · فُتِحَ البابُ.
es:
  # Hacerse, ponerse, volverse

  El español no tiene un solo verbo para become.

  - hacerse + profesión: Se hizo médico.
  - ponerse + estado temporal: Me puse triste.
  - volverse + cambio fuerte: Se volvió loco.
ja:
  # なる

  日本語では「なる」で変化を表します。

  - 名詞＋になる：医者になる。
  - い形容詞＋くなる：寒くなる。
  - な形容詞＋になる：静かになる。
zh:
  # 变成・成为・变得

  汉语用不同的词表示变化。

  - 变成／成为＋名词：她成为了医生。
  - 变得＋形容词：天气变得很冷。
  - 句末「了」表示变化：天黑了。
