en:
  # Result clauses

  so … that / such … that show a strong result.

  - so + adj + that · such + noun + that
  - Demand rose so sharply that prices spiked.
fr:
  # Propositions de conséquence

  Montrez la conséquence avec si… que / tellement… que.

  - si / tellement + adj + que… ; un tel + nom + que…
  - La demande a tellement augmenté que les prix ont flambé.
de:
  # Konsekutivsätze

  Zeigen Sie die Folge mit so… dass / derart… dass.

  - so + Adj/Adv + dass…; ein solches + Nomen + dass…
  - Die Nachfrage stieg so stark, dass die Preise explodierten.
am:
  # የውጤት አረፍተ ነገሮች

  በ… እስከ… / ስለዚህ ውጤትን ያሳዩ።

  - በጣም + ቅጽል + ስለዚህ…፤ እንደዚህ ያለ + ስም + ስለዚህ…
  - በዚህ ምክንያት / ስለዚህ በአረፍተ ነገሮች መካከል ያገናኛል።
ar:
  # جمل النتيجة

  أظهر النتيجة بـ لدرجة أنّ / بحيث.

  - جداً / إلى درجة أنّ…؛ مثل هذا + اسم + لدرجة أنّ…
  - ارتفع الطلب بشدة لدرجة أن الأسعار قفزت.
es:
  # Oraciones de resultado

  Muestra la consecuencia con tan… que / tal… que.

  - tan + adj/adv + que…; tal + sintagma nominal + que…
  - La demanda subió tan bruscamente que los precios se dispararon.
ja:
  # 結果の表現「〜て、〜ほどだ／そのため」

  程度と結果をつなぎます。

  - 需要が急増したため、価格が高騰した。
  - とても〜て、〜。／〜ほど〜。そのため／したがって。
zh:
  # 结果小句：如此……以至于

  用“如此……以至于／因此”表结果。

  - 如此＋形／副＋以至于……；这样的＋名词＋以至于……
  - 需求上升得太猛，以至于价格飙升。
