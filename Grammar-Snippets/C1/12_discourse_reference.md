en:
  # Discourse reference

  this/that and the former/the latter point back without repeating.

  - this/that → whole idea · the former / the latter
  - Inflation rose. This worries investors.
fr:
  # Référence discursive

  Renvoyez à des idées, pas seulement à des noms.

  - le premier / le second contraste deux mentions.
  - L’inflation a augmenté. Cela inquiète les investisseurs.
de:
  # Diskursreferenz

  Verweisen Sie auf Ideen, nicht nur auf Nomina.

  - dies/das kann auf ganze Sätze zeigen; solch + Nomen fasst zusammen.
  - Die Inflation stieg. Das beunruhigt Anleger. · Solche Behauptungen brauchen Belege.
am:
  # የንግግር ማጣቀሻ

  ስሞችን ብቻ ሳይሆን ሀሳቦችንም ያመልክቱ።

  - ይህ/ያ ሙሉ አረፍተ ነገርን ሊያመለክት ይችላል፤ እንደዚህ ያለ + ስም ያጠቃልላል።
  - የመጀመሪያው / የኋለኛው ሁለት ቀደምት ማጣቀሻዎችን ያነጻጽራል።
ar:
  # الإحالة الخطابية

  أشر إلى أفكار لا إلى أسماء فقط.

  - هذا/ذلك قد يحيل إلى جملة كاملة؛ مثل هذا + اسم يلخّص.
  - ارتفع التضخم. هذا يقلق المستثمرين. · مثل هذه الادعاءات تحتاج إلى أدلة.
es:
  # Referencia discursiva

  Señala ideas, no solo nombres.

  - esto/eso puede referirse a toda una cláusula; tal + nombre resume.
  - Subió la inflación. Esto preocupa a inversores. · Tales afirmaciones necesitan pruebas.
ja:
  # 談話指示

  名詞だけでなく考え全体を指します。

  - これ／それは節全体を指しうる。そうした＋名詞で要約。
  - インフレが上昇した。これは投資家を不安にさせる。・そうした主張には根拠が要る。
zh:
  # 篇章指代

  回指观点，而不只是名词。

  - 这／那可指整个小句；此类＋名词作概括。
  - 通胀上升了。这让投资者担忧。・此类说法需要证据。
