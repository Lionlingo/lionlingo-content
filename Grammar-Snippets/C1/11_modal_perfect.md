en:
  # Modal perfect

  must/might/should have + past participle looks back with attitude.

  - must have · might have · should have · can't have
  - She must have left. · You should have called.
fr:
  # Modalité au passé

  Spéculez ou jugez des événements passés.

  - a dû = forte déduction ; a pu / aurait pu = possibilité ; aurait dû = critique.
  - Elle a dû partir. · Tu aurais dû appeler.
de:
  # Modalverben im Perfekt

  Spekulieren oder urteilen Sie über Vergangenes.

  - muss … haben = starke Schlussfolgerung
  - Sie muss gegangen sein. · Du hättest anrufen sollen.
am:
  # ስለ ያለፈ ግምት

  ስለ ያለፉ ክስተቶች ይገምቱ ወይም ይፍረዱ።

  - መሆን ነበረበት = ትችት/ጥበቃ።
  - በእርግጥ… ነበር = ጠንካራ መደምደሚያ፤ ሊሆን ይችል ነበር = እድል።
ar:
  # أفعال الكيفية في الماضي

  خمّن أو احكم على أحداث ماضية.

  - لا بد أنّه = استنتاج قوي؛ ربما / قد = إمكانية؛ كان ينبغي = نقد.
  - لا بد أنها غادرت. · كان عليك أن تتصل.
es:
  # Modal + perfecto

  Especula o juzga sobre hechos pasados.

  - debe de haber = deducción fuerte; podría haber = posibilidad; debería haber = crítica.
  - Debe de haberse ido. · Deberías haber llamado.
ja:
  # 過去への推量・評価「〜たはず／〜たかもしれない」

  過去の事柄を推量・評価します。

  - 〜たに違いない＝強い推量。〜たかもしれない＝可能性。〜すべきだった＝批判。
  - 彼女はもう出たに違いない。・電話すべきだった。
zh:
  # 情态＋完成：一定／可能／本该……了

  对过去事件进行推测或评价。

  - 她一定已经走了。・你本该打电话的。
  - 一定已经＝强推测；可能已经＝可能性；本该＝批评／期望。
