en:
  # Concession

  although / even though admit a contrast, then continue.

  - although / even though · nonetheless / still
  - While the data are limited, the trend is clear.
fr:
  # Propositions concessives

  Admettez un point contraire sans annuler l’idée principale.

  - bien que / même si ; tout en + participe.
  - Bien que les données soient limitées, la tendance est claire.
de:
  # Konzessivsätze

  Räumen Sie einen Gegensatz ein, ohne die Hauptaussage aufzuheben.

  - obwohl / auch wenn; während manchmal konzessiv.
  - Obwohl die Daten begrenzt sind, ist der Trend klar.
am:
  # የመቀበል/ተቃርኖ አረፍተ ነገሮች

  ዋናውን ክርክር ሳያጠፉ ተቃራኒ ነጥብ ይቀበሉ።

  - ቢሆንም / ሆኖም / እንኳን እንደዚያ ቢሆንም።
  - ምንም እንኳን… ቢሆንም፤ ሆኖም በኋላ ያገናኛል።
ar:
  # جمل التنازل

  أقرّ بنقطة معارضة دون إلغاء الادعاء الرئيسي.

  - مع أنّ / رغم أنّ؛ بينما قد تكون تنازلية.
  - مع أن البيانات محدودة، فإن الاتجاه واضح.
es:
  # Oraciones concesivas

  Admite un punto contrario sin anular la tesis principal.

  - aunque / si bien / a pesar de que; mientras puede ser concesivo.
  - Aunque los datos son limitados, la tendencia es clara.
ja:
  # 譲歩の節

  対立点を認めつつ主張を保ちます。

  - 〜けれども／〜とはいえ／〜ながら。
  - データは限られているとはいえ、傾向ははっきりしている。
zh:
  # 让步小句

  承认对立点，但不取消主要论点。

  - 虽然／尽管／即使＋小句；而有时表让步。
  - 尽管数据有限，趋势仍然清楚。
