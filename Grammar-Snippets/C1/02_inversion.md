en:
  # Inversion

  Start with Never/Only… and flip the auxiliary for emphasis.

  - Never / Rarely / Only then + auxiliary + subject
  - Never have I seen such chaos.

ja:
  # 強調の語順

  日本語に英語型の助動詞倒置はありません。強調は「こそ」「のは…だ」「すら／さえ」や、否定語の前出しで行います。

  - こんな混乱は見たことがない。意見が一致することなどめったにない。そのときこそ初めて理解した。拒否したばかりか早く立ち去った。
  - 「見たことがない、こんな混乱は」は後置で余韻を残す。Never have I を「持っている私は見たことがない」と訳さない。
zh:
  # 前置与焦点强调（连…都／才）

  汉语几乎没有英语那种助动词与主语倒装。强调靠前置宾语或状语、用「连…都」「才」「甚至」，或用「是…的」。

  - 连这样的混乱我都没见过。我们很少达成一致。直到那时她才明白。他们不但拒绝，甚至提前走了。
  - 我从未见过如此混乱。我们很少意见一致。直到那时她才明白。他们不但拒绝，而且还早早离开了。
