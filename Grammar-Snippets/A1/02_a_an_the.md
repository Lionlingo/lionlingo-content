en:
  # a / an / the

  a/an introduces something new; the points to something specific.

  - a book · an apple · the window
  - a/an = one of many · the = specific
fr:
  # Articles

  L'article marque le genre, le nombre, et si le nom est connu.
de:
  # Artikel

  Der Artikel zeigt Geschlecht, Zahl und Fall.

  - Der Fall ändert den Artikel: Ich sehe den Lehrer (Akk.). Lernen Sie das Nomen immer mit A…

ar:
  # ال / النكرة

  ال تجعل الاسم معرفة.

  - نكرة: كتاب، تفاحة. معرفة: الكتاب، التفاحة. ال تلزم مع المعهود أو الجنس العام.
  - كتاب على الطاولة. · افتح النافذة.
es:
  # Artículos

  El artículo marca género, número y si el nombre es conocido.

  - Indefinido: un/una/unos/unas. Definido: el/la/los/las. Neutro lo + adjetivo: lo important…
  - un libro · una manzana.
ja:
  # 冠詞

  日本語に a や the はありません。初出か既知かは助詞と指示語で示します。

  - 初出・中立は「が」が多い。既出の話題は「は」。特定なら「この／その／あの」＋名詞。
  - 本があります。・窓を開けてください。・彼女は先生です。
zh:
  # 冠词

  汉语没有冠词。第一次提到常用数量词，已知用「这／那」或直接说名词。

  - 无定：一＋量词＋名词 → 一本书。有定：这／那＋量词＋名词 → 那扇窗户。
  - 有一本书。・请打开窗户。・她是老师。
