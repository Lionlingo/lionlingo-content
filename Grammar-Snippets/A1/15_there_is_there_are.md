en:
  # there is / there are

  Use there is/are to say that something exists in a place.

  - there is + singular · there are + plural
  - There is a book. · There are two chairs.
fr:
  # Il y a

  Dites qu’une chose existe ou se trouve quelque part.

  - il y a + singulier ou pluriel (forme unique).
  - Il y a un parc près d’ici. · Il y a deux cafés.
de:
  # Es gibt

  Sagen Sie, dass etwas vorhanden ist.

  - es gibt + Akkusativ (Einzahl/Mehrzahl gleich).
  - Es gibt einen Park in der Nähe. · Es gibt zwei Cafés.
am:
  # መኖር / መኖር አለ (አለ / አሉ)

  አንድ ነገር በቦታ እንዳለ ይግለጹ።

  - አሉታ፦ የለም / የሉም። ጥያቄ፦ አለ?
  - ነጠላ፦ አለ። ብዙ፦ አሉ።
ar:
  # هناك / يوجد

  قل إن شيئاً موجوداً في مكان ما.

  - النفي: ليس هناك… السؤال: هل هناك…؟
  - هناك حديقة قريبة. · يوجد مقهىان.
es:
  # Hay

  Di que algo existe o está en un lugar.

  - Hay un parque cerca. · Hay dos cafés.
  - hay sirve para singular y plural.
ja:
  # 存在の「あります／います」

  場所に何かがある／だれかがいることを言います。

  - もの：あります。人・動物：います。
  - 近くに公園があります。・カフェが二つあります。
zh:
  # 表示存在的「有」

  说明某处存在某物或某人。

  - 地方 + 有 + 名词。
  - 附近有一个公园。・有两家咖啡馆。
