en:
  # Wh- questions

  Start with what, where, when, who, why, or how.

  - What / Where / When / Who / Why / How + …?
  - Where do you live? · What is this?
fr:
  # Questions en qu- / interrogatifs

  Demandez une information avec qui, que, où, quand, pourquoi, comment.

  - Mot interrogatif + est-ce que / inversion.
  - Où habites-tu ? · Comment t’appelles-tu ?
de:
  # W-Fragen

  Fragen Sie nach Informationen mit wer, was, wo, wann, warum, wie.

  - Fragewort + Verb (Position 2) + Subjekt …
  - Wo wohnst du? · Wie heißt du?
am:
  # የጥያቄ ቃላት

  በማን፣ ምን፣ የት፣ መቼ፣ ለምን፣ እንዴት መረጃ ይጠይቁ።

  - ማን / ምን / የት / መቼ / ለምን / እንዴት።
  - የት ነው የምትኖረው? · ስምህ ማን ነው?
ar:
  # أسئلة الاستفهام

  اطلب معلومات بـ من، ما، أين، متى، لماذا، كيف.

  - أداة الاستفهام + الجملة.
  - من / ما / ماذا / أين / متى / لماذا / كيف.
es:
  # Preguntas con interrogativos

  Pide información con quién, qué, dónde, cuándo, por qué, cómo.

  - Interrogativo + verbo + sujeto (o sujeto omitido).
  - ¿Dónde vives? · ¿Cómo te llamas?
ja:
  # 疑問詞の質問

  だれ・なに・どこ・いつ・なぜ・どうで情報を尋ねます。

  - 疑問詞を文に置き、語尾を「か」や上昇イントネーションに。
  - どこに住んでいますか。・お名前は何ですか。
zh:
  # 疑问词提问

  用谁、什么、哪里、什么时候、为什么、怎么问信息。

  - 你住在哪里？・你叫什么名字？
  - 疑问词放在要问的成分位置，句末用疑问语气。
