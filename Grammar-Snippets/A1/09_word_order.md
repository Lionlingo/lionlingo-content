en:
  # Word order

  Keep the usual order: who does what.

  - Subject + verb + object
  - I read books. · She likes tea.
fr:
  # Ordre des mots dans l’affirmative

  Gardez un ordre clair sujet–verbe–complément.

  - Sujet + verbe + complément.
  - Je bois du café. · Elle lit un livre chaque jour.
de:
  # Grundwortstellung in Aussagesätzen

  Im Hauptsatz steht das finite Verb an Position 2.

  - Subjekt oft Position 1, Verb Position 2, Rest danach.
  - Ich trinke Kaffee. · Sie liest jeden Tag ein Buch.
am:
  # የአረፍተ ነገር ቅደም ተከተል

  በቀላል አረፍተ ነገር ርዕሰ ጉዳይ–ነገር–ግሥ ቅደም ተከተል ይጠብቁ።

  - ርዕሰ ጉዳይ + ነገር + ግሥ።
  - በአማርኛ ግሥ ብዙ ጊዜ በመጨረሻ ይመጣል።
ar:
  # ترتيب الجملة الخبرية

  احفظ ترتيباً واضحاً في الجمل البسيطة.

  - شائع: فعل + فاعل + مفعول، أو مبتدأ + خبر.
  - أنا أشرب القهوة. · هي تقرأ كتاباً كل يوم.
es:
  # Orden básico en oraciones afirmativas

  Mantén un orden claro sujeto–verbo–complemento.

  - Sujeto + verbo + objeto/complemento.
  - Yo bebo café. · Ella lee un libro cada día.
ja:
  # 平叙文の基本語順

  日本語は「〜が／は＋〜を＋動詞」が基本です。

  - 述語（動詞・形容詞・名詞＋です）は文末。
  - 私はコーヒーを飲みます。・彼女は毎日本を読みます。
zh:
  # 陈述句基本语序

  简单句保持「主语＋谓语＋宾语」的清晰顺序。

  - 主语 + 动词 + 宾语／补语。
  - 我喝咖啡。・她每天看书。
