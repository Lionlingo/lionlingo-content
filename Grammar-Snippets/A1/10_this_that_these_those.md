en:
  # this / that / these / those

  this/these = near you; that/those = farther away.

  - this/these = near · that/those = far
  - This book · Those chairs
fr:
  # Démonstratifs : ce, cette, ces / celui…

  Désignez ce qui est proche ou plus loin.

  - C’est mon sac. · Ce sont mes amis.
  - ce/cet/cette/ces devant un nom ; ceci/cela pour pointer.
de:
  # Demonstrativpronomen: dieser, dieser, das…

  Zeigen Sie auf nahe oder entfernte Dinge.

  - Achten Sie auf Kasus und Numerus: dieses Buch, diese Bücher.
  - dieser/diese/dieses (nah); jener oft für weiter weg.
am:
  # አመላካች

  ቅርብ ወይም ሩቅ የሆኑ ነገሮችን ያመልክቱ።

  - ይህ/እነዚህ = ቅርብ፤ ያ/እነዚያ = ሩቅ።
  - ቁጥርን ያስታውሱ፦ ይህ መጽሐፍ · እነዚህ መጻሕፍት።
ar:
  # أسماء الإشارة: هذا، هذه، ذلك، تلك

  أشر إلى القريب أو البعيد.

  - هذه حقيبتي. · أولئك أصدقائي.
  - هذا/هذه للقريب؛ ذلك/تلك للبعيد.
es:
  # Demostrativos: este, ese, aquel

  Señala lo cercano, medio o lejano.

  - Esta es mi bolsa. · Aquellos son mis amigos.
  - este/estos (cerca), ese/esos (medio), aquel/aquellos (lejos).
ja:
  # 指示語：これ・それ・あれ／この・その・あの

  近いもの・相手側・遠いものを指します。

  - これ／それ／あれ＝もの；この／その／あの＝名詞の前。
  - これは私のかばんです。・あれは友達です。
zh:
  # 指示词：这、那、这些、那些

  指近处或远处的人或物。

  - 这是我的包。・那些是我的朋友。
  - 这／这些＝近；那／那些＝远。
