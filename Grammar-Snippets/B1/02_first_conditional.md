en:
  # First conditional

  If + present, will + verb for a real future possibility.

  - If + present, will + verb
  - If you study, you will pass.

es:
  # Condicional real

  Para un resultado futuro probable, si lleva presente de indicativo y el otro verbo va en…

  - No ponga futuro tras si: Si estudiarás es incorrecto. Si + imperfecto de subjuntivo es ir…
  - Si estudias, aprobarás. · Si no llueve, saldremos.
ja:
  # 現実的な条件（ば／たら／と）

  起こりうる結果は「ば」「たら」、必然・習慣は「と」です。will を条件節に入れません。

  - 勉強すれば、合格します。・雨が降らなければ、出かけます。
  - 勉強すれば合格します。勉強したら合格するでしょう。雨が降ると中止です。
zh:
  # 真实条件（如果……就）

  可能实现的条件用「如果／要是……就」。条件句用现在情况，结果用将来或情态。

  - 如果＋条件，就＋结果。要是明天下雨，我们就不去。
  - 如果你学习，就会及格。・如果不下雨，我们就出去。
