en:
  # must / have to / should

  must/have to = needed; should = good advice.

  - must/have to = obligation · should = advice · don't have to = optional
  - You must wear a seatbelt.
fr:
  # must / have to / should

  devoir et il faut expriment l'obligation.

  - je dois + infinitif. il faut + infinitif / que + subjonctif. tu devrais + infinitif.
  - Tu dois mettre la ceinture.
de:
  # must / have to / should

  müssen = Notwendigkeit.

  - Modalverb + Infinitiv am Ende: Du musst den Gurt anlegen. Du solltest dich ausruhen.

es:
  # must / have to / should

  tener que y hay que marcan obligación.

  - No debes aparcar = prohibido. No tienes que venir = opcional. No hay que confundirlos.
  - Debes ponerte el cinturón.
ja:
  # なければならない／べき／なくてもいい

  義務は「なければならない」、助言は「べきです」、不要は「なくてもいい」で、禁止の「てはいけない」と違います。

  - シートベルトをしなければなりません。・休むべきです。・来なくてもいいです。
  - 〜なければなりません。〜べきです。〜てはいけません（禁止）。〜なくてもいいです（任意）。
zh:
  # 必须、得、应该

  必须／得＝强制义务。应该＝建议。不必／不用＝没有必要，不是禁止。

  - 必须／得＋动词。应该＋动词。禁止：不许／不能。无需：不必／不用。
  - 你必须系安全带。・我明天得工作。・你应该休息。・你不必来。
