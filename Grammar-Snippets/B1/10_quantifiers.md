en:
  # Quantifiers

  Choose many/much/some/any to match count vs uncount nouns.

  - many/a few + count · much/a little + uncount · some/any
  - I have some time. · Are there any seats?
fr:
  # Quantificateurs

  Parlez de quantité sans chiffre exact.

  - dans les négations : pas de…
  - J’ai un peu de temps. · Y a-t-il des places ?
de:
  # Quantoren

  Sprechen Sie über Mengen ohne genaue Zahl.

  - viele / wenige + Plural; viel / wenig + Unzählbares.
  - Ich habe etwas Zeit. · Gibt es noch Plätze?
am:
  # ብዛት አመልካቾች፦ ጥቂት፣ ብዙ፣ አንዳንድ

  ያለ ትክክለኛ ቁጥር ስለ ብዛት ይናገሩ።

  - ብዙ / ጥቂት + ስም፤ አንዳንድ ለማያውቁ።
  - ጥቂት ጊዜ አለኝ። · ቦታዎች አሉ?
ar:
  # محددات الكمية: بعض، أي، كثير، قليل

  تحدث عن الكمية دون رقم دقيق.

  - في النفي والسؤال: أي / أيّة غالباً.
  - كثير من / قليل من + اسم؛ بعض في الإثبات.
es:
  # Cuantificadores: algo, mucho, poco, unos…

  Habla de cantidad sin números exactos.

  - muchos / unos pocos + contable; mucho / un poco de + incontable.
  - Tengo un poco de tiempo. · ¿Hay asientos?
ja:
  # 数量表現：少し・たくさん・いくつか

  正確な数なしで量を言います。

  - 可算っぽく：いくつか。不可算っぽく：少しの時間。
  - 少し時間があります。・席はありますか。
zh:
  # 量词与数量词：一些、很多、一点

  不说准确数字也能谈数量。

  - 很多／几个＋可数；很多／一点＋不可数概念。
  - 我有一点时间。・还有座位吗？
