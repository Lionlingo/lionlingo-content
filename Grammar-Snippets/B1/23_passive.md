en:
  # The passive

  The passive shows what happens to something.

  - be + past participle: The door is opened.
  - Use by for the doer: The book was written by Tom.
  - Past: was or were + participle: The house was built in 1990.
fr:
  # La voix passive

  La voix passive met l'objet au premier plan.

  - être + participe passé : La porte est ouverte.
  - par + celui qui fait : Le livre a été écrit par Paul.
  - On remplace souvent le passif : Ici, on parle français.
de:
  # Das Passiv

  Das Passiv zeigt, was mit etwas geschieht.

  - werden + Partizip II: Die Tür wird geöffnet.
  - von für die handelnde Person: Das Buch wurde von Paul geschrieben.
  - Zustandspassiv mit sein: Die Tür ist geöffnet.

  يُبنى الفعل للمجهول بتغيير حركاته.

  - الماضي: كَتَبَ → كُتِبَ الكتابُ

es:
  # La voz pasiva

  El español usa la pasiva con ser o la pasiva refleja con se.

  - ser + participio: El libro fue escrito por Pablo.
  - se + verbo: Se habla español aquí.
  - El participio concuerda: Las puertas fueron abiertas.
ja:
  # 受身

  日本語の受身は、動詞に〜れる・〜られるを付けます。

  - 食べる → 食べられる · 書く → 書かれる
  - する人は「に」：本は田中さんに書かれました。
  - 迷惑の受身：雨に降られました。
zh:
  # 被动句

  汉语常用「被」表示被动。

  - 「被」＋动作者＋动词：门被他打开了。
  - 动作者可以省略：门被打开了。
  - 没有「被」也可以表示被动：饭做好了。
