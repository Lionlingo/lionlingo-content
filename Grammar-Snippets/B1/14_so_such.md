en:
  # so / such

  so + adjective; such + (a/an) + adjective + noun.

  - so + adj/adv · such (+ a/an) + adj + noun
  - so good that… · such a kind person
fr:
  # Si / tellement / un tel pour l’intensité

  Renforcez le sens et introduisez une conséquence.

  - si / tellement + adjectif ; un(e) tel(le) + nom.
  - si … que … pour le résultat.
de:
  # So / solch für Verstärkung

  Verstärken Sie die Bedeutung und leiten Sie eine Folge ein.

  - so + Adjektiv/Adverb; solch ein + Adjektiv + Nomen.
  - so … dass … für die Folge.

  Intensifica el significado e introduce una consecuencia.

  - tan + adjetivo/adverbio; tal + (un/una) + adjetivo + nombre.
