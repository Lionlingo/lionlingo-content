en:
  # Tag questions

  A short tag at the end checks or softens the statement.

  - + statement → − tag · − statement → + tag
  - You're coming, aren't you?
fr:
  # Questions-tags / n’est-ce pas

  Vérifiez ou invitez l’accord en fin de phrase.

  - Souvent : n’est-ce pas ? / hein ? / d’accord ?
  - Tu viens, n’est-ce pas ? · Il fait froid, hein ?
de:
  # Frageanhängsel: nicht wahr / oder?

  Prüfen oder Zustimmung einladen am Satzende.

  - Steigende Intonation = echte Frage.
am:
  # የማረጋገጫ ጥያቄዎች (አይደል?)

  በአረፍተ ነገር መጨረሻ ስምምነት ይጠይቁ።

  - አዎንታዊ → አሉታዊ መጨረሻ፤ አሉታዊ → አዎንታዊ።
  - ቀዝቃዛ ነው፣ አይደል? · መዋኘት አትችልም፣ ትችያለሽ?
ar:
  # أسئلة التذييل / أليس كذلك؟

  تحقق أو اطلب الموافقة في نهاية الجملة.

  - جملة مثبتة → أليس كذلك؟؛ منفية → أليس كذلك؟ بصيغة مناسبة.
  - نبرة صاعدة = سؤال حقيقي.
es:
  # Colectillas: ¿verdad? / ¿no?

  Comprueba o invita al acuerdo al final.

  - Afirmación → ¿no? / ¿verdad?; negación → ¿verdad? / ¿sí?
  - Vienes, ¿verdad? · Hace frío, ¿no?
ja:
  # 確認の「ね／よね／だろう」

  文末で確認や同意を求めます。

  - 来ますよね。・寒いですね。
  - 〜ね。・〜よね。・〜でしょう？
zh:
  # 附加问句：是吗／对吧

  在句末核对或征求同意。

  - 肯定句＋是吗／对吧；否定句＋是吗。
  - 你来，对吧？・很冷，是吧？
