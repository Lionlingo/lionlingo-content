en:
  # Given → new

  Put given information first and new information later.

  - Known info first · new focus last
  - What matters now is timing.
fr:
  # Donné → nouveau

  Ordonnez pour que le connu précède le focus nouveau.

  - Ce qui compte maintenant, c’est le timing. · C’est le timing qui comptait.
  - Partez du contexte partagé ; finissez par la nouveauté.
de:
  # Gegeben → neu

  Ordnen Sie so, dass Bekanntes vor dem neuen Fokus steht.

  - Was jetzt zählt, ist das Timing. · Es war das Timing, das zählte.
  - Vom gemeinsamen Kontext ausgehen; mit der Neuigkeit enden.

ar:
  # بنية المعلومات

  رتّب الجمل بحيث يسبق المعروفُ البؤرةَ الجديدة.

  - ما يهم الآن هو التوقيت. · إنّ التوقيت هو ما كان مهماً.
  - ابدأ من سياق مشترك؛ اختم بالخبر الذي تريد إبرازه.
es:
  # Dado → nuevo

  Ordena para que lo conocido preceda al foco nuevo.

  - Lo que importa ahora es el momento. · Fue el momento lo que importó.
  - Parte del contexto compartido; termina con la novedad.
ja:
  # 既知→新情報

  既知情報を先に、新しい焦点を後に置きます。

  - 共有文脈から始め、目立たせたい新情報で終える。
  - 今重要なのはタイミングだ。・重要だったのはタイミングだった。
zh:
  # 已知→新信息

  安排语序，使已知在前、新焦点在后。

  - 现在重要的是时机。・重要的正是时机。
  - 从共享语境起笔，以要突出的新信息收尾。
