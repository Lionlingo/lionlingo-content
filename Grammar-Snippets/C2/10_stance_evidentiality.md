en:
  # Stance & evidentiality

  Show whose view it is and how you know.

  - apparently / reportedly · clearly / arguably
  - Reportedly, costs rose.
fr:
  # Stance / évidence

  Montrez la source du savoir et le degré d’engagement.

  - Apparemment / selon… marquent la source ; clairement / sans doute la force.
  - Selon les reports, les coûts ont augmenté.
de:
  # Stance / Evidentialität

  Zeigen Sie Wissensquelle und Verbindlichkeitsgrad.

  - angeblich / Berichten zufolge markieren Quelle; klar / wohl Stärke.
  - Berichten zufolge stiegen die Kosten. · Man kann sagen, das Design ist fehlerhaft.

es:
  # Postura / evidencialidad

  Muestra cómo sabes algo y cuán fuerte te comprometes.

  - al parecer / según se informa marcan fuente; claramente / cabría argumentar la fuerza.
  - Según se informa, subieron los costes. · Cabe argumentar que el diseño es defectuoso.
