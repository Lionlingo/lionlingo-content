en:
  # Plural nouns

  Most English nouns add an ending to make the plural.

  - Most nouns add -s: book → books · cat → cats
  - Add -es after s, x, ch, sh: box → boxes · bus → buses
  - Some nouns are irregular: man → men · child → children
fr:
  # Le pluriel

  En français, on ajoute -s à la plupart des noms. Le -s ne se prononce pas.

  - On ajoute -s à la plupart des noms : un livre → des livres · un chat → des chats
  - Les noms en -eau et -al changent : un bateau → des bateaux · un cheval → des chevaux
  - Quelques noms ne changent pas : un nez → des nez · un prix → des prix
de:
  # Der Plural

  Der deutsche Plural hat fünf Endungen: -e, -er, -(e)n, -s oder keine.

  - Die meisten Nomen bekommen eine Endung: Hund → Hunde · Frau → Frauen
  - Oft kommt ein Umlaut dazu: Haus → Häuser · Apfel → Äpfel
  - Manche Nomen bleiben gleich: Lehrer → Lehrer · Mädchen → Mädchen
am:
  # ብዙ ቁጥር

  በአማርኛ ብዙ ቁጥር ለመሥራት ቅጥያ ይጨመራል።

  - -ኦች ወይም -ዎች ይጨመራል፦ ቤት → ቤቶች · ልጅ → ልጆች
  - አናባቢው ሊለወጥ ይችላል፦ ሰው → ሰዎች · ሙዝ → ሙዞች
  - አንዳንድ ቃላት የራሳቸው ቅርጽ አላቸው፦ መጽሐፍ → መጻሕፍት · ንጉሥ → ነገሥት
ar:
  # الجمع

  للجمع في العربية ثلاثة أنواع.

  - جمع المذكر السالم: مهندس → مهندسون · معلّم → معلّمون
  - جمع المؤنث السالم: معلّمة → معلّمات · طالبة → طالبات
  - جمع التكسير تتغيّر فيه الكلمة: كتاب → كُتُب · رجل → رجال
es:
  # El plural

  En español, casi todos los nombres añaden -s o -es.

  - Si acaba en vocal, añade -s: casa → casas · libro → libros
  - Si acaba en consonante, añade -es: papel → papeles · ciudad → ciudades
  - La z cambia a c: lápiz → lápices · luz → luces
ja:
  # 複数

  日本語の名詞は、普通は複数形になりません。

  - 数詞を付けて数えます：本 → 本三冊 · 猫 → 猫二匹
  - 人には「たち」を付けます：私 → 私たち · 子ども → 子どもたち
  - 繰り返して複数を表す言葉もあります：人 → 人々 · 山 → 山々
zh:
  # 复数

  汉语名词一般不变化。

  - 数量用数词加量词：书 → 三本书 · 猫 → 两只猫
  - 人称代词加「们」：我 → 我们 · 你 → 你们
  - 指人的名词也可以加「们」：孩子 → 孩子们 · 老师 → 老师们
