en:
  # To become

  English uses become and get for change.

  - become + noun: She became a doctor. · He became a teacher.
  - get + adjective for change: It gets dark. · I got tired.
  - turn or go for sudden change: The leaves turned red. · He went pale.
fr:
  # Devenir

  Devenir exprime un changement.

  - devenir + nom : Elle est devenue médecin. · Il est devenu professeur.
  - devenir + adjectif : Il devient grand. · Elle devient timide.
  - devenir peut dire un grand changement : Il est devenu fou. · Elle est devenue célèbre.
de:
  # Werden

  Werden zeigt, dass sich etwas verändert.

  - werden + Nomen heißt: etwas wird zu etwas: Sie wird Ärztin. · Er wird Lehrer.
  - werden + Adjektiv zeigt Veränderung: Es wird dunkel. · Ich werde müde.
  - werden zeigt auch große Veränderungen: Er wurde berühmt. · Es wurde Nacht.

ar:
  # صار وأصبح

  تعبّر العربية عن التحوّل بصار وأصبح.

  - صار أو أصبح + اسم منصوب: صارت طبيبةً. · أصبح معلّماً.
  - صار أو أصبح + صفة: أصبح الجوّ بارداً. · صرتُ متعباً.
  - التحوّل الكبير بـ أصبح: أصبح مشهوراً. · أصبحت ثريّةً.
es:
  # Hacerse, ponerse, volverse

  El español no tiene un solo verbo para este cambio.

  - hacerse + profesión: Se hizo médico. · Se hizo profesora.
  - ponerse + estado temporal: Me puse triste. · Se puso rojo.
  - volverse + cambio fuerte: Se volvió loco. · Se volvió famoso.
ja:
  # なる

  日本語では「なる」で変化を表します。

  - 名詞 + になる：医者になる。 · 先生になりました。
  - 形容詞は〜くなる、〜になる：寒くなる。 · 静かになりました。
  - 急な変化も「なる」で表します：暗くなってきた。 · 有名になりました。
zh:
  # 变成・成为・变得

  汉语用不同的词表示变化。

  - 变成或成为加名词：她成为了医生。 · 他变成了老师。
  - 变得加形容词：天气变得很冷。 · 我变得很累。
  - 句末「了」表示变化：天黑了。 · 天冷了。
