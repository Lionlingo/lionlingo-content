en:
  # Participial phrases

  English can use a participle phrase after a noun instead of a relative clause.

  - -ing replaces who is: the man who is standing there → the man standing there · prices that are rising → rising prices
  - The past participle replaces who was: the student who was praised → the student praised by the teacher · the letter that was sent → the letter sent yesterday
  - to + verb replaces that must be: a problem that must be solved → a problem to be solved · a task that must be done → a task to be done
fr:
  # Les participes qui décrivent un nom

  Le français peut utiliser un participe après le nom à la place d'une relative.

  - Le participe présent remplace qui + verbe : un homme qui parle trois langues → un homme parlant trois langues · un enfant qui sourit → un enfant souriant
  - Le participe passé remplace qui a été : l'élève qui a été félicité → l'élève félicité par le professeur · la lettre qui a été envoyée → la lettre envoyée hier
  - à + infinitif remplace qui doit être : un problème qui doit être résolu → un problème à résoudre · une tâche qui doit être faite → une tâche à faire
de:
  # Erweitertes Partizipialattribut

  Ein Partizip mit Ergänzungen steht vor dem Nomen und ersetzt einen Relativsatz.

  - Das Partizip I ersetzt einen aktiven Relativsatz: die Preise, die steigen → die steigenden Preise · der Mann, der dort steht → der dort stehende Mann
  - Das Partizip II ersetzt einen Passivsatz: der Schüler, der gelobt wurde → der gelobte Schüler · der Brief, der geschickt wurde → der geschickte Brief
  - zu + Partizip I heißt muss werden: eine Aufgabe, die gelöst werden muss → eine zu lösende Aufgabe · ein Problem, das gelöst werden muss → ein zu lösendes Problem

ar:
  # الصفة المشتقة

  في العربية يصف اسم الفاعل واسم المفعول الاسم الذي قبلهما.

  - اسم الفاعل يحلّ محل الجملة: الأسعار التي ترتفع → الأسعار المرتفعة · الرجل الذي يقف → الرجل الواقف
  - اسم المفعول يحلّ محل الجملة: الطالب الذي مُدح → الطالب الممدوح · الرسالة التي أُرسلت → الرسالة المرسلة
  - واجب يدل على الضرورة: مشكلة ينبغي حلّها → مشكلة واجبة الحل · مهمة يجب إنجازها → مهمة واجبة الإنجاز
es:
  # Los participios que describen un nombre

  El español puede usar un participio o un adjetivo en -nte después del nombre.

  - El adjetivo en -nte sustituye a que + verbo: los precios que crecen → los precios crecientes · un hombre que sonríe → un hombre sonriente
  - El participio sustituye a que fue: el alumno que fue felicitado → el alumno felicitado · la carta que fue enviada → la carta enviada
  - por + infinitivo dice lo pendiente: un problema que hay que resolver → un problema por resolver · una tarea que hay que hacer → una tarea por hacer
ja:
  # 長い連体修飾

  日本語では、長い説明を名詞の前に置きます。

  - 〜ている で説明を名詞の前に置きます：価格が上がっている → 上がっている価格 · 人が立っている → 立っている人
  - 〜た で説明を名詞の前に置きます：先生にほめられた → ほめられた生徒 · 送られた → 送られた手紙
  - 〜べき は必要を表します：解決しなければならない → 解決すべき問題 · やらなければならない → やるべき仕事
zh:
  # 长定语

  汉语把长的说明放在名词前面，用「的」连接。

  - 动词说明放在「的」前面：价格在上涨 → 上涨的价格 · 人站着 → 站着的人
  - 被动的说明也放在名词前：学生被表扬 → 被表扬的学生 · 信被寄走 → 被寄走的信
  - 「需要」表示必要：问题需要解决 → 需要解决的问题 · 工作需要完成 → 需要完成的工作
