en:
  # Participles

  English has two participles: -ing and the past participle.

  - The present participle ends in -ing: run → running · eat → eating
  - The past participle ends in -ed or is irregular: close → closed · eat → eaten
  - Participles work with be and have: The door is closed. · I have eaten.
fr:
  # Les participes

  Le français a un participe présent et un participe passé.

  - Le participe présent finit par -ant : manger → mangeant · parler → parlant
  - Le participe passé finit par -é, -i ou -u : manger → mangé · finir → fini
  - Avec être, le participe s'accorde : Elle est partie. · Ils sont partis.
de:
  # Partizip I und II

  Das Deutsche hat zwei Partizipien.

  - Das Partizip I bekommt ein -d: laufen → laufend · lachen → lachend
  - Das Partizip II hat ge- am Anfang: machen → gemacht · gehen → gegangen
  - Als Adjektiv bekommt es eine Endung: Das lachende Kind spielt. · Die geschlossene Tür ist alt.

ar:
  # اسم الفاعل واسم المفعول

  تصف هاتان الصيغتان الفاعل أو المفعول.

  - اسم الفاعل يصف من يفعل: كتب → كاتب · لعب → لاعب
  - اسم المفعول يصف ما وقع عليه الفعل: كتب → مكتوب · فتح → مفتوح
  - يُستعملان صفةً: الباب مفتوحٌ. · هذا رجلٌ كاتبٌ.
es:
  # El gerundio y el participio

  El español tiene gerundio y participio.

  - El gerundio acaba en -ando o -iendo: hablar → hablando · comer → comiendo
  - El participio acaba en -ado o -ido: hablar → hablado · comer → comido
  - Como adjetivo, el participio concuerda: La puerta está cerrada. · Los libros están cerrados.
ja:
  # 動詞で名詞を説明する

  日本語には分詞がありません。動詞を名詞の前に置いて説明します。

  - 〜ている で今の動作を表します：走る → 走っている · 食べる → 食べている
  - 〜た で完了した状態を表します：閉まる → 閉まった · 食べる → 食べた
  - 動詞は名詞を前から説明します：走っている人は先生です。 · 閉まったドアは古いです。
zh:
  # 动词表示状态

  汉语没有分词。用「着」「了」和「的」表示状态。

  - 「着」表示状态：开 → 开着 · 坐 → 坐着
  - 「了」表示完成：吃 → 吃了 · 关 → 关了
  - 动词加「的」说明名词：跑步的人是老师。 · 关着的门很旧。
