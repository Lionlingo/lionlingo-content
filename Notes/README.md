# Notes

Each topic folder is one lesson. The four markdown files are the sections of that lesson, not single sentences.

```text
Notes/A1/vocabulary/topic_01_greetings_and_introductions/
├── reading.md
├── notes.md
├── vocabulary.md
└── questions.md
```

`notes.md` carries the lesson id, slug, category, and order. Categories are `grammar`, `vocabulary`, `culture`, and `conversation`.
