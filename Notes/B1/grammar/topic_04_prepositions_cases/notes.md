## short

en:
- Location says where something is. Direction says where it is moving. The marker often changes between the two.

fr:
- La position dit où quelque chose est. La direction dit où cela va. Le marqueur change souvent entre les deux.

de:
- Lage sagt, wo etwas ist. Richtung sagt, wohin es sich bewegt. Das Zeichen wechselt oft zwischen beidem.

am:
- መገኛ ነገር የት እንዳለ ይላል። አቅጣጫ ወዴት እንደሚሄድ ይላል። ምልክቱ ብዙ ጊዜ በሁለቱ መካከል ይቀያየራል።

es:
- La posición dice dónde está algo. La dirección dice hacia dónde se mueve. La marca suele cambiar entre las dos.

## explanation

en:
  Place words do two jobs. One set answers where something is resting. Another set answers where it is going. Some languages use different words for the two jobs. Others use the same word and change an ending or a case. Learn the pair for each common place: city, station, table, office.
fr:
  Les mots de lieu ont deux rôles. Une série répond où quelque chose repose. Une autre répond où cela va. Certaines langues utilisent des mots différents. D'autres gardent le même mot et changent une finale. Apprenez la paire pour chaque lieu courant : ville, gare, table, bureau.
de:
  Ortswörter haben zwei Aufgaben. Eine Reihe antwortet, wo etwas ruht. Eine andere antwortet, wohin es geht. Manche Sprachen nutzen verschiedene Wörter. Andere behalten dasselbe Wort und ändern eine Endung. Lernen Sie das Paar für jeden häufigen Ort: Stadt, Bahnhof, Tisch, Büro.

  የቦታ ቃላት ሁለት ሥራ አላቸው። አንዱ ነገር የት እንዳረፈ ይመልሳል። ሌላው ወዴት እንደሚሄድ ይመልሳል። አንዳንድ ቋንቋዎች የተለያዩ ቃላት ይጠቀማሉ። ሌሎች አንድ ቃል ይዘው መጨረሻ ይቀይራሉ።
ar:
  كلمات المكان لها وظيفتان. مجموعة تجيب أين يستقر الشيء. وأخرى تجيب إلى أين يذهب. بعض اللغات تستخدم كلمات مختلفة. وغيرها تبقي الكلمة وتغيّر النهاية.
es:
  Las palabras de lugar tienen dos tareas. Una serie responde dónde descansa algo. Otra responde hacia dónde va. Unas lenguas usan palabras distintas. Otras mantienen la palabra y cambian una terminación.
ja:
  場所の語には二つの働きがあります。一つはどこにあるか、もう一つはどこへ向かうかです。別の語を使う言語も、同じ語で語尾だけ変える言語もあります。町、駅、机、事務所のような身近な場所の対を覚えましょう。
zh:
  地点词有两种作用。一组回答某物停在哪里，另一组回答它往哪里去。有的语言用不同的词，有的语言用同一个词但改变词尾。把城市、车站、桌子、办公室这些常见地点的一对说法学会。

## rules

en:
- Location answers where something is.
- Direction answers where it is going.
- The marker may be a different word or a different ending.
- Learn a location-direction pair for each common place.

fr:
- La position répond où quelque chose est.
- La direction répond où cela va.
- Le marqueur peut être un autre mot ou une autre finale.
- Apprenez une paire position-direction pour chaque lieu courant.

de:
- Lage antwortet, wo etwas ist.
- Richtung antwortet, wohin es geht.
- Das Zeichen kann ein anderes Wort oder eine andere Endung sein.
- Lernen Sie für jeden häufigen Ort ein Paar aus Lage und Richtung.
