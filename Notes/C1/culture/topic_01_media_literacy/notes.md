## explanation

en:
  A source is a person, a document, or a recording a report relies on. Framing is the choice of words, order, and pictures that makes one reading easier than another. Bias is a steady lean in that choice. Fact-checking asks whether a stated claim matches a record you can inspect. Separate three layers: what happened, what someone says about it, and what the report wants you to feel. If a layer is missing, say so.
fr:
  Une source est une personne, un document ou un enregistrement sur lequel un reportage s'appuie. Le cadrage est le choix des mots, de l'ordre et des images qui rend une lecture plus facile qu'une autre. Un biais est une inclinaison stable dans ce choix. La vérification demande si une affirmation énoncée correspond à une trace que vous pouvez inspecter.
de:
  Eine Quelle ist eine Person, ein Dokument oder eine Aufnahme, auf die ein Bericht sich stützt. Rahmung ist die Wahl von Wörtern, Reihenfolge und Bildern, die eine Lesart leichter macht als eine andere. Eine Schlagseite ist eine stetige Neigung in dieser Wahl. Eine Prüfung fragt, ob eine genannte Behauptung zu einer Spur passt, die Sie ansehen können.

## rules

en:
- A source is a person, a document, or a recording.
- Framing is the choice that makes one reading easier.
- Separate the event, the claim about it, and the feeling the report invites.
- A missing source is a reason to pause, not a reason to repeat the claim.

fr:
- Une source est une personne, un document ou un enregistrement.
- Le cadrage est le choix qui rend une lecture plus facile.
- Séparez l'événement, l'affirmation à son sujet et le sentiment que le reportage invite.
- Une source manquante est une raison de pauser, non une raison de répéter l'affirmation.

de:
- Eine Quelle ist eine Person, ein Dokument oder eine Aufnahme.
- Rahmung ist die Wahl, die eine Lesart leichter macht.
- Trennen Sie das Ereignis, die Behauptung darüber und das Gefühl, das der Bericht einlädt.
- Eine fehlende Quelle ist ein Grund innezuhalten, kein Grund, die Behauptung zu wiederholen.
