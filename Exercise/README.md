# Exercise

Practice sentences grouped by CEFR level, exercise type, and lesson.

```text
Exercise/A1/vocabulary/lesson_01/01_morning.md
```

Each markdown file is one sentence. Under `en:`, `fr:`, and the other language labels, the first bullet is the title and the second is the sentence. Vocabulary and grammar links are the sections below.

Lessons are numbered `lesson_01`, `lesson_02`, and so on. File order is the `order` field in the front matter.
